# Security policy

Do not open a public issue containing a vulnerability, report content, recovery credential or personal data. Use GitHub's private vulnerability reporting for this repository. A monitored security mailbox must replace the `.invalid` deployment default before any public pilot.

Include the affected version, impact, reproduction steps using synthetic data and suggested remediation. We will acknowledge only when an actual monitored channel is configured; no response-time promise is made in this pre-release demo.

Real-data intake is prohibited until the release checklist is signed. If a secret or real report is found in the repository, stop distribution, preserve minimal evidence and follow `docs/incident-response.md`.
