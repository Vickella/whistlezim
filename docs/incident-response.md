# Incident response

Detect → contain → preserve minimal evidence → assess confidentiality/integrity/availability → coordinate with the controller and qualified counsel → notify authorities/people where applicable → eradicate and recover → document lessons.

Immediately close intake for suspected KEK/pepper leakage, credential compromise, cross-tenant disclosure, malicious file, provider suspension, failed backup, impersonation or insider misuse. Rotate affected material with reviewed migration, revoke sessions/grants, and avoid putting report content into tickets or chat. Notification scope and timing require fact-specific legal assessment; this runbook invents no universal deadline.
